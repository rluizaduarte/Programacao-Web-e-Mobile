para navegação em react, em geral usa-se a tag Link
para navegação <a href="link"> texto que aparece no lugar que clica (poderia ser uma imagem tb por exemplo) </a>

todos os atributos ficam na abertura da tag

id - identificadores (como se fosse variavel)
pra fazer um link dentro da propria pagina é necessario colocar essa seção da pagina como id
qnd usar o a href, basta colocar o #(id definido) que ele "desce" pra onde for esse id

o atributo target possibilita personalizar o link. ele tem alguns valores possiveis
blank - abre uma nova aba (mais usado)
